

# GiveWiZe - Charity Discovery Platform

A modern, trustworthy charity discovery website that helps users find and support causes they care about through personalized recommendations.

---

## 🎨 Design Foundation

**Brand Identity**
- Clean, modern design that conveys trust and warmth
- Deep teal (#0D9488) as primary color - trustworthy and calming
- Warm coral (#F97316) as accent - energetic call-to-actions
- Neutral grays for text and backgrounds
- Rounded corners and subtle shadows for approachability

**Responsive Layout**
- Desktop: Full navigation with logo, menu items, and user actions
- Mobile: Collapsible hamburger menu with smooth animations
- Consistent spacing and typography throughout

---

## 📄 Pages & Features (MVP)

### 1. Home Page
- Hero section with compelling headline and "Take the Quiz" CTA
- Featured charity categories preview
- Quick stats (charities listed, causes supported)
- How it works section

### 2. Explore Charities
- Search bar with filters (category, size, location)
- Category cards for easy browsing (Health, Education, Environment, etc.)
- Charity cards showing name, category, rating, and impact summary
- "Add to compare" and "Save to favorites" buttons

### 3. Charity Detail Page
- Full charity profile with mission, impact metrics, ratings
- Key information (location, size, focus areas)
- Donation links/information
- Add to favorites functionality

### 4. Comparison Tool
- Side-by-side comparison of selected charities (up to 3)
- Compare ratings, impact metrics, overhead costs
- Clear visual indicators for differences

### 5. Quiz Page
- Multi-step questionnaire about user values and interests
- Questions about causes, giving preferences, impact priorities
- Results page with personalized charity recommendations
- Option to save results (requires login)

### 6. About Page
- GiveWiZe mission and story
- How charity vetting works
- Trust indicators and methodology

### 7. User Features (requires login)
- Favorites/saved charities list
- Quiz results history
- Simple profile management

---

## 🔧 Backend (Lovable Cloud)

**Database Tables**
- Charities (name, category, description, ratings, metrics, etc.)
- Categories (for organizing charities)
- User favorites (linking users to saved charities)
- Quiz results (storing user quiz responses and recommendations)

**Authentication**
- Email signup/login
- Optional social login (Google)

---

## 📱 MVP Scope

Starting simple and iterating:
